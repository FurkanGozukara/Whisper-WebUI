Surface Scan

What the app exposes vs what the backend serves

The main Gradio app exposes more workflows than the FastAPI backend. The backend is focused on queued processing and task retrieval, while the app adds YouTube, microphone, translation tabs, presets, and richer interactive controls.

Full App Features

Gradio + runtime

File Transcription

Audio and video upload, live transcript output, multi-format subtitle export.

YouTube Workflow

Direct YouTube link transcription in the app UI.

Mic Capture

Microphone recording flow for direct subtitle generation.

Batch Folder Mode

Folder scan, optional subdirectory traversal, overwrite control, multiple formats at once.

Translation Modes

Whisper translate-to-English plus subtitle translation tabs for DeepL API and NLLB.

Cleanup Stack

Silero VAD, UVR background-music removal, and optional speaker diarization.

Runtime Controls

Model, language, compute type, batching, word timestamps, prompts, offload, presets.

Output Formats

SRT, WebVTT, TXT, LRC, JSON, and TSV are available in the app UI.

Backend API

FastAPI
POST
/transcription

Queues transcription for uploaded audio or video with whisper, VAD, BGM separation, and diarization parameters.

POST
/vad

Runs voice activity detection and returns a speech timeline as a queued task result.

POST
/bgm-separation

Queues background music separation and stores instrumental and vocal outputs for download.

GET
/task/{identifier}

Polls queued task state, progress, duration, and final result payload.

GET
/task/file/{identifier}

Downloads zipped BGM separation results. Delete and list-all task endpoints exist in code but are disabled.

Backend root redirects to /docs, and Redoc is available at /redoc. The backend transcription router currently constructs FasterWhisperInference, so the REST path is tied to faster-whisper even though the full app supports three runtime implementations.
